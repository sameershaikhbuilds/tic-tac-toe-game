# 🎮 Tic Tac Toe Game

A simple and responsive Tic Tac Toe game built using **HTML**, **CSS**, and **Vanilla JavaScript**.

## 🚀 Live Features

- 🎲 Two-player gameplay (X & O)
- 🏆 Automatic winner detection
- 🤝 Draw detection
- 🔄 Reset game button
- 📱 Responsive design
- 🎨 Clean and minimal UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
